# Source inventory and parameter status

The workplan asks that every parameter be labelled **measured**, **literature-derived** or **assumed**. This inventory adds **unverified** (a number presented as sourced whose source could not be traced or does not match the data) and **heuristic** (a tuning choice, not an estimate). Last reviewed 11 September 2026.

| Curated candidate-gene catalogue (11 loci) | `real_data/bgd_qtl_loader.py` | Literature-derived, **verified 11 Sep 2026**.
